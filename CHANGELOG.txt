[v0.3.7] 2026-05-05
-------------------
モバイルの横スクロール解消。

複数の要因が viewport を僅かにはみ出していたため複合対応:
- html / body: overflow-x: hidden + max-width: 100vw を明示
  fixed要素や子の overflow を確実に viewport で頭打ちに
- .page-shell::before: inset 0 -40px → inset 0

  代わりに breakpoint 別に明示的な margin で「広めに見せる」だけに
  720px 以下では margin 0 で収める（モバイル安全）
  720-1099px では space-5 ぶん左右に広げる
  1100px 以上では -6% に広げる
- .sprite-track: overflow visible → hidden
  どんぐりのバウンドピーク (約58px) は track 高さ 220px - sprite 132 = 88px の余裕に収まるので
  hidden に戻して横方向のはみ出しを完全に防ぐ

[v0.3.2] 2026-05-05
-------------------
スプライト点滅の真の原因解明 — ピクセル整数アライメント方式に統一。

ユーザー提供の動作確認済み HTML を解析した結果、点滅の真因は
**ブラウザのバックグラウンド画像補間によるサブピクセル位置ズレ**であった。
- 旧: 要素 45×110 + bg-size 800% (= 360px) → 元画像 1440px を 4x ダウンスケール
  各フレーム移動が 45px = 整数だが、bg 内部座標は 1440÷4=360 で 4の倍数しか整列せず
  サブピクセル境界で1px未満のズレが発生 → 点滅として知覚

- 新: 動作確認版と同じ pattern を採用
  - 要素を **元画像のフレームサイズと同一** に設定 (180×440 / 180×420)
  - background-size を **ピクセル値** で 1440×440 / 1440×420 に明示
  - background-position を **ピクセル値** で 0 → -1440 に steps(8) 移動
  - 表示サイズ調整は別レイヤー .sprite-stage の transform: scale で
    （補間影響をスプライト本体から完全分離）

- HTML構造に sprite-stage ラッパー追加（全6HTML）:
  shiba: <sprite-pos><sprite-stage><sprite-shiba></...
  acorn: <sprite-pos><acorn-physics><sprite-stage><sprite-acorn></...

- sprite.js は frame cycling と X 移動の責務を CSS animation に戻し、
  物理バウンド・位置トラッキング・可視性切替・マウス検知 のみに簡素化

- sprite-track の overflow を visible に変更（scaled 表示なら BOX 領域でも
  視覚的に飛び出さないため。jump も自由に上方向へ伸びる）

- 表示サイズ: PC scale(0.3) → 54×132、モバイル scale(0.22) → 約40×97
  以前の 45×110 と近いが、サブピクセル整列が完璧で点滅根絶

[v0.2.2] 2026-05-05
-------------------
追加修正。

スプライト点滅の根本対応
- 原因判明: CSS `steps(8)` が from 0% to -800% で t=1 の瞬間に「9コマ目（=画像範囲外の空白）」を描画してしまい、ループ毎に空白フレームが視認されていた
- PNGの透過自体は問題なし（α=0 in 白部分、α=255 in 毛色部分を確認済み）
- 修正: 8コマぶんのキーフレーム明示 + step-end タイミング関数で空白フレームを排除
  ```css
  @keyframes sprite-walk {
    0%   { background-position-x: 0%; }
    12.5% { background-position-x: -100%; }
    ...
    87.5% { background-position-x: -700%; }
    100% { background-position-x: 0%; }  /* 明示的にframe 0へ戻す */
  }
  animation: sprite-walk 0.32s step-end infinite;
  ```
